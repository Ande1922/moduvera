# Produce reproducible and traceable application artifacts

Build inputs are version-controlled and converged, and App Assemblies produce reproducible JAR artifacts and software bills of materials with source/build identity attached. Container construction, image scanning, runtime user/filesystem policy, immutable image references, publication, signing and verification remain outside this ADR until the deployment design is confirmed.

Evidence: Q398-Q405. Q406-Q416 are retained as historical container and deployment proposals and are deferred from the current delivery; see [the question index](../grill/question-index.md).
